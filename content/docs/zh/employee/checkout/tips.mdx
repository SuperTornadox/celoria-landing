# 小费处理

本文介绍结账时如何为客人添加小费，以及不同支付方式下小费的处理方法。

## 适用角色

- 前台 (Receptionist)
- 员工 (Employee)
- 经理 (Manager)

## 前置条件

- 已登录员工账号
- 拥有 `payments:process` 权限
- 已进入结账流程

## 添加小费

### 快捷比例选择

结账时，系统显示小费快捷按钮：

| 按钮 | 说明 |
|------|------|
| 15% | 基础小费 |
| 18% | 标准小费 |
| 20% | 优质服务 |
| 25% | 非常满意 |

点击对应按钮，系统自动按**税前金额**计算小费并加入账单。


### 自定义金额

如客人想给其他金额：

1. 点击 **自定义**
2. 输入小费金额
3. 金额自动加入账单

### 不给小费

点击 **无小费** 跳过小费步骤，直接进入支付。

## 现金支付的小费

现金支付时，系统会**自动计算小费**。

<Steps>

### 1. 确认应付金额

系统显示服务总金额（含税）。

### 2. 输入收到的现金

在「收到金额」栏输入客人给的钱数。也可以用快捷按钮（+$5、+$10、+$20）快速填入。

### 3. 查看自动计算结果

系统自动将**超出账单的部分**识别为小费：

- **小费金额**（绿色显示）= 收到金额 - 应付金额 - 找零
- **应找金额**（黄色显示）= 多余零钱

**举例：** 账单 $45，客人给 $60。系统判定 $15 为小费，找零 $0。

### 4. 确认支付

核对金额无误后，点击 **确认支付**。

</Steps>

<Callout type="info">
小费会按门店设置的规则自动分配给服务技师。
</Callout>


## 刷卡支付的小费

刷卡支付时，小费在刷卡**之前**添加：

<Steps>

### 1. 选择小费金额

在支付页面选择小费比例或输入自定义金额。

### 2. 确认总金额

系统显示：服务金额 + 小费 = 刷卡总额。

### 3. 刷卡支付

使用 POS 机完成支付，金额已包含小费。

</Steps>

## 支付后修改小费

某些情况下需要在支付完成后调整小费：

<Steps>

### 1. 找到交易记录

在 **交易记录** 中找到对应的订单。

### 2. 点击修改小费

点击小费金额旁的 **编辑** 按钮。

### 3. 输入新金额

输入正确的小费金额。

### 4. 确认修改

系统更新小费记录。如果是刷卡支付，可能需要通过 POS 机调整。

</Steps>

<Callout type="warning">
如果 POS 机已锁定小费金额，需要手动记录差额并在日结时处理。
</Callout>

## 小费去向

小费最终在日结时统一分配：

| 项目 | 说明 |
|------|------|
| 分配对象 | 提供服务的技师 |
| 门店抽成 | 按门店设置的比例（默认 10%） |
| 分配方式 | 按服务金额比例 或 平均分配 |
| 分配时间 | 日结流程中统一处理 |

详细的分配规则见 [日结小费分配](/docs/manager/day-end-closeout/tips-distribution)。

## 常见问题

<FAQ>
  <FAQItem question="客人现金给多了，怎么区分小费和找零？">
    系统默认将超出账单的部分全部计为小费。如果客人需要找零，在确认支付前手动调整小费金额即可。
  </FAQItem>
  <FAQItem question="一个订单有多个技师，小费怎么分？">
    小费按门店设置的规则分配。常见方式是按每位技师的服务金额比例分配，也可以设为平均分配。分配在日结时统一进行。
  </FAQItem>
  <FAQItem question="客人想单独给某个技师现金小费怎么办？">
    可以在结账时选择「无小费」跳过系统小费，技师自行保管现金小费。或者在系统中手动录入并指定技师。
  </FAQItem>
  <FAQItem question="小费比例可以修改吗？">
    可以。管理员在 **设置 > 支付设置** 中可以修改小费预设比例和是否允许自定义金额。
  </FAQItem>
</FAQ>
