# 消息设置

配置系统发送邮件和短信所使用的服务商，支持测试发送和状态查看。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Marketing → Messaging Settings

## 邮件服务商

系统支持两种邮件服务商，选择其一：

### AWS SES

| 设置项 | 说明 |
|--------|------|
| 区域 (Region) | AWS SES 所在区域（如 us-east-1） |
| 发件邮箱 | 发送邮件使用的邮箱地址 |
| 回复邮箱 | 客人回复时接收的邮箱 |
| 沙箱模式 | 测试模式，仅发送到已验证地址 |

### Resend

| 设置项 | 说明 |
|--------|------|
| 发件人名称 | 邮件中显示的发件人 |
| 发件邮箱 | 发送邮件使用的邮箱 |
| 回复邮箱 | 回复接收邮箱 |

**测试邮件**：配置完成后可点击 **Send Test** 发送一封测试邮件验证配置正确。

## 短信服务商

系统支持两种短信服务商，选择其一：

### Twilio

| 设置项 | 说明 |
|--------|------|
| 发送号码 | Twilio 分配的发送手机号 |
| Messaging Service SID | Twilio 消息服务 ID |
| 状态回调 URL | 接收发送状态的 Webhook 地址 |

### Telnyx

| 设置项 | 说明 |
|--------|------|
| 发送号码 | Telnyx 分配的发送手机号 |
| Messaging Profile ID | Telnyx 消息配置 ID |
| 状态回调 URL | 接收发送状态的 Webhook 地址 |

**测试短信**：配置完成后可发送测试短信验证。

## 服务商状态

页面会显示：
- 当前服务商的连接状态
- 配额使用情况
- 已验证的发件人列表

<Callout type="warning">
邮件和短信服务商的 API Key 需通过环境变量配置，不在此页面设置。联系技术团队获取配置帮助。
</Callout>
