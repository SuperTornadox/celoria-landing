# 终端管理

管理与门店配对的 POS 收款终端，查看设备状态和在线情况。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → Terminals 标签页

## 终端列表

显示所有已配对终端的信息：

| 字段 | 说明 |
|------|------|
| 设备名称 | 终端显示名（如 "Celoria POS"） |
| 设备 ID | 唯一设备标识符 |
| 关联门店 | 该终端配对的门店 |
| 状态 | active（活跃）或 revoked（已撤销） |
| 在线状态 | 当前是否在线 |
| 最后活跃 | 最近一次连接时间 |

可按门店筛选终端列表。

## 配对新终端

<Steps>

### 1. 点击添加

点击 **Add Terminal** 按钮。

### 2. 选择门店

选择要配对的门店。

### 3. 在 POS 设备上确认

POS 设备自动发现并完成配对。

### 4. 配对成功

终端出现在列表中，状态为 active。

</Steps>

## 撤销终端

如需停用某个终端：

1. 在终端列表中找到目标设备
2. 点击 **Revoke** 按钮
3. 确认撤销

<Callout type="warning">
撤销后该终端无法再用于收款。如需重新使用，需重新配对。
</Callout>
