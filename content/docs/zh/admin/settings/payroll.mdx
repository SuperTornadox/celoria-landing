# 薪酬设置

配置员工的提成模式、佣金比例，支持按职位和个人覆盖。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限
- 需要开启 `payroll` 功能

## 进入设置

**路径**: 侧边栏 → Settings → Payroll 标签页

## 租户默认值

全局的薪酬默认配置：

| 设置项 | 说明 | 范围 |
|--------|------|------|
| 默认佣金比例 | 员工服务收入的提成百分比 | 0% - 100% |
| 默认薪酬模式 | 员工薪酬的计算方式 | 见下方 |
| 指定技师奖励 | 客人指定技师时的额外提成 | 0% - 100% |

**薪酬模式说明**：

| 模式 | 说明 |
|------|------|
| 仅时薪 (hourly_only) | 按小时计薪，不计提成 |
| 底薪 + 提成 (commission_plus_base) | 固定底薪加服务提成 |
| 取较高者 (greater_of) | 比较时薪和提成，取金额更高的方案 |

## 职位级别覆盖

为不同职位设置独立的佣金比例和薪酬模式：

1. 在 **Job Title Overrides** 区域找到目标职位
2. 设置该职位的佣金比例
3. 选择薪酬模式（或留空使用默认值）

每个职位旁会显示对应的员工人数。

## 员工佣金分配

查看所有员工最终适用的佣金配置：

| 列 | 说明 |
|----|------|
| 员工姓名 | 员工名称 |
| 佣金比例 | 实际适用的比例 |
| 来源 | 配置来源（员工覆盖 / 职位覆盖 / 租户默认） |

**优先级**：员工个人覆盖 → 职位覆盖 → 租户默认值

可按门店筛选查看。

<Callout type="info">
薪酬设置变更不会影响已结算的历史记录，仅对后续服务生效。
</Callout>
