# Guest App 定制

自定义 Guest App（客人端）的外观、品牌元素、首页模块布局和功能开关。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → Guest App 标签页

## 欢迎页面

配置客人打开 App 时的欢迎屏幕：

| 设置项 | 说明 |
|------|------|
| 头部图片 | 欢迎页顶部大图（支持裁切和焦点设置） |
| 图片类型 | 静态图片或动态图 |
| 遮罩透明度 | 图片上方的暗色遮罩（0 - 100%） |
| 标题 | 欢迎标题文字 |
| 副标题 | 欢迎副标题文字 |

## 品牌设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 主题色 | App 的主色调 | #D4AF37（金色） |
| App 名称 | 显示在 App 内的名称 | 沙龙名称 |
| Logo | App 内显示的品牌 Logo | - |

## 首页模块布局

拖拽排列首页显示的模块，可开关每个模块的显示：

| 模块 | 说明 |
|------|------|
| Hero Banner | 顶部大图横幅 |
| Quick Actions | 快捷操作按钮 |
| Services | 服务列表 |
| Gift Cards | 礼品卡入口 |
| Loyalty Points | 积分显示 |
| Promotions | 促销活动 |

## 功能开关

控制 App 内功能的可用性：

| 功能 | 说明 |
|------|------|
| 显示价格 | 是否在服务列表中展示价格 |
| 允许选择技师 | 客人预约时是否可以指定技师 |
| 显示时长 | 是否展示服务预计时长 |
| 启用礼品卡 | 是否开放礼品卡功能 |
| 启用积分 | 是否开放积分系统 |
| 显示技师评分 | 是否展示技师评价 |
| 启用在线支付 | 是否支持 App 内支付 |

## Hero Banner

独立配置首页顶部大图：
- 上传图片并设置裁切区域
- 设置焦点（确保关键内容在不同屏幕上可见）
- 调整遮罩透明度

## 自定义消息

可编辑 App 内各处显示的文案，如预约成功提示、联系信息等。
