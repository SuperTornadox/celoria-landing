# 考勤设置

配置员工打卡考勤的规则，包括打卡方式、迟到判定和自动提醒。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)
- 经理 (Manager)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → 考勤设置（独立页面）

或直接访问 **Settings → Time Clock**

## 打卡方式

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| PIN 打卡 | 允许员工使用 4-6 位 PIN 码打卡 | 开 |
| 一键打卡 | 已登录员工可一键打卡（无需 PIN） | 关 |

<Callout type="info">
两种打卡方式可同时启用。PIN 打卡适合共用终端场景，一键打卡适合员工使用个人设备。
</Callout>

## 出勤规则

| 设置项 | 说明 | 范围 | 默认值 |
|--------|------|------|--------|
| 迟到容忍 | 超过排班开始时间多久标记为迟到 | 0 - 60 分钟 | 0 |
| 早退提醒 | 提前多久离开标记为早退 | 0 - 120 分钟 | 0 |
| 每周补卡上限 | 每位员工每周可申请的补卡次数 | 0 - 不限 | - |

## 自动提醒

| 设置项 | 说明 |
|--------|------|
| 打卡提醒 | 是否在排班结束前发送提醒 |
| 提醒时间 | 在排班结束前多少分钟发送提醒 |

## 按门店覆盖

考勤设置支持按门店单独配置：

1. 在页面顶部选择 **Tenant Default**（全局默认）或特定门店
2. 修改该门店的考勤规则
3. 保存后仅该门店使用覆盖值
