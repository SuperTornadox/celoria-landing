# 通用设置

配置沙龙的基础区域和财务参数，支持按门店覆盖默认值。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → General 标签页

## 区域设置

| 设置项 | 说明 | 可选值 |
|--------|------|--------|
| 时区 | 系统显示和报表的时区 | ET / CT / MT / PT / AKT / HT / CST / JST / GMT / CET |
| 日期格式 | 日期的显示格式 | MM/DD/YYYY / DD/MM/YYYY / YYYY-MM-DD |
| 时间格式 | 12 小时制或 24 小时制 | 12h / 24h |
| 每周起始日 | 排班和报表的周起始 | Sunday / Monday |

## 财务设置

| 设置项 | 说明 | 范围 |
|--------|------|------|
| 货币 | 系统使用的货币单位 | USD / EUR / GBP / CNY / JPY / CAD / AUD |
| 税率 | 默认税率百分比 | 0% - 100% |
| 含税显示 | 价格是否已含税 | 开 / 关 |

## 押金设置

| 设置项 | 说明 | 范围 |
|--------|------|------|
| 要求押金 | 预约时是否要求客人支付押金 | 开 / 关 |
| 押金比例 | 押金占服务总价的百分比 | 0% - 100% |

## 按门店覆盖

通用设置支持 **门店级别覆盖**：

1. 在设置页面下方找到 **Store Overrides** 表格
2. 选择需要覆盖的门店
3. 修改该门店的特定值（如不同门店税率不同）
4. 保存后该门店使用覆盖值，其他门店继续使用默认值

<Callout type="info">
设置优先级从高到低：门店覆盖值 → 租户默认值 → 系统默认值。删除门店覆盖后自动回退到租户默认值。
</Callout>
