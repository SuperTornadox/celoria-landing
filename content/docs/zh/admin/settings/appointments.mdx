# 预约设置

配置预约系统的各项规则，包括预约时间、取消政策、自动通知等。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → Appointments 标签页

## 预约规则

| 设置项 | 说明 | 范围 | 默认值 |
|--------|------|------|--------|
| 最远预约天数 | 客人最多可提前多少天预约 | 1 - 365 天 | 30 天 |
| 最短取消通知 | 取消预约需提前多少小时通知 | 0 - 72 小时 | 0 |
| 间隔缓冲时间 | 两个预约之间的缓冲时间 | 0 - 60 分钟（步长 5） | 0 |
| 时段间隔 | 可选预约时段的最小间隔 | 10 / 15 / 20 / 30 分钟 | 15 |

## 爽约处理

| 设置项 | 说明 | 范围 |
|--------|------|------|
| 最大爽约次数 | 达到该次数后触发处理动作 | 0 - 10 次 |
| 爽约动作 | 超过爽约限制后的处理方式 | 警告 / 需确认 / 封禁 |

**爽约动作说明**：
- **警告 (warn)**: 仅记录，不阻止新预约
- **需确认 (require_confirm)**: 预约需经理手动确认
- **封禁 (block)**: 自动阻止该客人继续预约

## 在线预约

| 设置项 | 说明 |
|--------|------|
| 允许客户自助预约 | 客人可通过 Guest App 自行预约 |
| 要求手机验证 | 预约时需短信验证码确认 |
| 启用公开预约链接 | 生成可分享的预约页面链接 |

## 通知提醒

| 设置项 | 说明 |
|--------|------|
| 短信提醒 | 预约前自动发送短信提醒客人 |
| 邮件提醒 | 预约前自动发送邮件提醒客人 |

<Callout type="info">
通知提醒需先在「消息设置」中配置好 SMS / Email 服务商。未配置时开关无效。
</Callout>

## 按门店覆盖

所有预约设置均支持门店级别覆盖，不同门店可设置不同的预约规则。
