# 支付方式设置

管理沙龙支持的支付方式，包括内置方式、自定义方式和小费预设。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `settings:manage` 权限

## 进入设置

**路径**: 侧边栏 → Settings → Payment Methods 标签页

## 内置支付方式

| 方式 | 说明 | 可关闭 |
|------|------|--------|
| 现金 (Cash) | 现金收款 | 否（始终可用） |
| 信用卡/借记卡 (Card) | 刷卡收款 | 是 |
| POS 终端 (POS Terminal) | 通过 CodePay POS 终端收款 | 是 |
| 手动录入 (Manual Entry) | 手动记录其他方式的收款 | 是 |

## 自定义支付方式

可添加额外的支付方式用于记账：

1. 在自定义区域点击 **Add**
2. 输入支付方式名称（如 "Gift Card"、"Check"）
3. 保存

<Callout type="info">
自定义支付方式仅用于记账分类，不会触发实际支付流程。
</Callout>

## 小费预设 (POS)

配置 POS 终端上显示的小费百分比选项：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 预设百分比 | POS 屏幕显示的小费选项 | 15%, 18%, 20%, 25% |
| 计算基础 | 小费按税前还是税后金额计算 | 税前 (pre_tax) |

**修改小费预设**：
1. 编辑预设百分比列表
2. 选择计算基础（税前 / 税后）
3. 保存后 POS 终端下次结账时生效
