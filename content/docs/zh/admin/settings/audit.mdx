# 审计日志

查看系统中所有操作的详细记录，用于安全审计和变更追踪。

## 适用角色

- 超级管理员 (Super Admin)
- 管理员 (Admin)

## 前置条件

- 拥有 `audit:view` 权限

## 进入设置

**路径**: 侧边栏 → Settings → Audit 标签页

或直接访问 **Audit Center**

## 日志信息

每条审计记录包含：

| 字段 | 说明 |
|------|------|
| 操作类型 | 创建 (create) / 更新 (update) / 删除 (delete) 等 |
| 目标类型 | 操作对象（用户、设置、预约等） |
| 目标 ID | 被操作对象的唯一标识 |
| 操作人 | 执行操作的用户姓名和邮箱 |
| 时间 | 操作发生的时间（含时区） |
| IP 地址 | 操作来源 IP |
| 变更详情 | 具体修改了什么字段、旧值和新值 |

## 筛选和搜索

| 筛选项 | 说明 |
|--------|------|
| 日期范围 | 按起止日期筛选 |
| 操作类型 | 按 create / update / delete 等类型筛选 |
| 目标类型 | 按操作对象类型筛选 |
| 操作人 | 按姓名或邮箱搜索 |

## 导出日志

点击 **Export** 按钮将审计日志导出为 CSV 文件，用于外部审计或存档。

## 统计摘要

页面顶部显示各操作类型的统计数字，快速了解近期系统活动。

<Callout type="info">
审计日志为只读，无法修改或删除。所有设置变更、权限调整、用户管理操作都会自动记录。
</Callout>
