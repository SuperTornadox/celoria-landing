# 服务照片与作品集

本文介绍如何使用服务前后对比照片，帮助门店记录服务效果、沉淀技师作品集，并在获得授权时导出营销素材。

## 适用角色

- 技师 (Employee)
- 经理 (Manager)
- 管理员 (Admin)

## 前置条件

- 技师需要拥有 `photos:manage` 权限，并且只能为自己被分配的服务上传照片。
- 经理或管理员需要拥有 `photos:view` 权限才能查看作品集。
- 导出营销素材需要 `photos:export` 权限，并且只能导出已获得营销授权的照片。

## 技师拍摄服务照片

<Steps>

### 1. 打开已分配的服务

技师在 Employee App 中进入自己的预约或服务详情。

### 2. 拍摄 Before 照片

服务开始前拍摄 Before 照片。系统会压缩图片并移除定位等设备元数据。

### 3. 拍摄 After 照片

服务完成后拍摄 After 照片。若需要重拍，同一服务同一类型只保留最新有效照片。

### 4. 等待上传完成

上传失败时，App 会进入待重试状态。多次失败后会显示失败状态，需要重新拍摄或稍后重试。

</Steps>

## 经理查看作品集

经理在 Web Admin 的服务照片页面查看门店范围内的照片。

可用筛选项包括：

| 筛选项 | 说明 |
|------|------|
| 门店 | 只显示自己有权限查看的门店 |
| 日期 | 按服务日期缩小范围 |
| 员工 | 查看某位技师的作品 |
| 服务分类 | 按美甲、美睫、护理等分类筛选 |
| 照片类型 | 查看 Before、After 或全部照片 |

<Callout type="info">
门店范围由权限控制决定。经理不会看到自己无权访问门店的服务照片。
</Callout>

## 导出营销素材

导出前请确认照片有明确的营销授权。

1. 在服务照片页面筛选目标照片
2. 选择需要导出的照片
3. 点击导出
4. 下载系统生成的压缩包

导出结果会区分：

| 结果 | 说明 |
|------|------|
| 已包含 | 客人已同意营销使用的照片 |
| 已排除 | 客人未同意或授权状态未知的照片 |

<Callout type="warning">
客人未授权或授权未知的照片不能用于营销导出。它们仍可在有权限的内部服务记录中查看。
</Callout>

## 客人查看自己的照片

客人可以在 Guest 页面查看自己的服务照片历史。客人查看自己的服务记录不受营销授权影响，即使客人不同意营销使用，也仍可查看自己的服务照片。

## 隐私删除和纠纷保留

当客人提交隐私删除请求时，系统会删除对应的照片记录和对象文件，并保留审计证据。

如果照片关联到正在处理的投诉、纠纷或法律保留，删除会暂停，等待经理或管理员复核。

## 常见问题

<FAQ>
  <FAQItem question="可以导出没有营销授权的照片吗？">
    不可以。营销导出只包含明确同意营销使用的照片，未同意或授权未知的照片会被排除。
  </FAQItem>
  <FAQItem question="客人不同意营销使用，还能看自己的照片吗？">
    可以。营销授权只影响营销导出，不影响客人查看自己的服务历史。
  </FAQItem>
  <FAQItem question="技师可以上传别人的服务照片吗？">
    不可以。技师只能为自己被分配的服务上传照片，未授权服务会被拒绝。
  </FAQItem>
</FAQ>
