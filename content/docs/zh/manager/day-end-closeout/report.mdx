# 日结报表

日结完成后，系统自动生成当日经营报表。本文介绍报表包含的内容以及如何导出和使用。

## 适用角色

- 经理 (Manager)
- 管理员 (Admin)

## 前置条件

- 日结流程已完成
- 拥有 `closeout:manage` 权限

## 报表内容

### 销售汇总

日结报表首先显示当日整体销售数据：

| 指标 | 说明 |
|------|------|
| 总营收 | 当日所有订单的总金额 |
| 服务收入 | 美甲服务的收入 |
| 产品销售 | 零售产品的收入 |
| 折扣总额 | 当日所有折扣和优惠的合计 |
| 退款总额 | 当日退款金额合计 |
| **净收入** | 总营收 - 折扣 - 退款 |


### 支付方式明细

按支付方式分类的收款记录：

| 支付方式 | 显示内容 |
|----------|---------|
| 现金 | 现金收款总额、实际清点金额、差异 |
| 信用卡/借记卡 | 刷卡总额、交易笔数 |
| 礼品卡 | 礼品卡消费总额 |
| 会员储值 | 储值余额消费总额 |
| 其他 | 挂账等其他方式 |

<Callout type="info">
如果现金实际清点金额与系统记录有差异，报表会用黄色（≤$5）或红色（>$20）标注提醒。
</Callout>

### 小费汇总

| 指标 | 说明 |
|------|------|
| 小费总额 | 当日收到的全部小费 |
| 门店抽成 | 门店按比例提取的部分 |
| 实际分配 | 分配给技师的小费总额 |
| 分配人数 | 参与分配的技师人数 |

### 员工业绩

每位当日上班的员工一行：

| 列 | 说明 |
|----|------|
| 员工姓名 | 技师名称 |
| 服务数量 | 当日完成的服务数 |
| 服务收入 | 该技师贡献的营收 |
| 小费收入 | 分配到的小费金额 |
| 合计收入 | 服务收入 + 小费 |


## 查看报表

日结完成后自动跳转到报表页面。也可以从历史记录进入：

<Steps>

### 1. 进入日结历史

点击 **管理 > 日结 > 历史记录**。

### 2. 选择日期

找到要查看的日期，点击进入。

### 3. 查看报表

在详情页中点击 **查看报表**。

</Steps>

## 导出报表

报表支持多种导出方式：

| 方式 | 格式 | 适用场景 |
|------|------|---------|
| 打印 | 纸质 | 存档或张贴公示 |
| 导出 PDF | .pdf | 电子存档、发送给管理层 |
| 导出 Excel | .xlsx | 数据分析、月度汇总 |
| 发送邮件 | 邮件附件 | 发送给店长或老板 |

<Steps>

### 1. 打开报表页面

进入日结详情 > 报表。

### 2. 点击导出

点击右上角的 **导出** 按钮。

### 3. 选择格式

选择需要的导出格式。

### 4. 确认导出

文件自动下载，或邮件发送到指定邮箱。

</Steps>

## 如何读懂报表

### 关注重点

- **净收入 vs 昨日** — 对比每日营收变化
- **支付差异** — 现金差异是否在合理范围内（$5 以内为正常）
- **人均产值** — 净收入 ÷ 当日员工数，衡量效率
- **小费占比** — 小费 ÷ 服务收入，反映客户满意度

### 异常标识

报表中可能出现的提示：

| 标识 | 含义 | 建议 |
|------|------|------|
| 黄色警告 | 现金差异 $5-$20 | 检查是否有找零误差 |
| 红色警告 | 现金差异 >$20 | 需要排查原因并记录 |
| 蓝色标注 | 有手动折扣 | 核实折扣是否合理 |

## 常见问题

<FAQ>
  <FAQItem question="报表数据和实际收银不一致怎么办？">
    先检查是否所有订单都已结账。如果确认有差异，在日结的「支付核对」步骤中记录差异原因。差异会体现在报表中。
  </FAQItem>
  <FAQItem question="可以修改已生成的报表吗？">
    日结锁定后报表不能直接修改。如需更正，需要管理员先解锁日结记录，修改后重新锁定。所有修改会记录在审计日志中。
  </FAQItem>
  <FAQItem question="报表能自动发送给老板吗？">
    可以。在 **设置 > 日结设置** 中配置自动邮件接收人，每次日结完成后报表会自动发送。
  </FAQItem>
  <FAQItem question="怎么看月度汇总？">
    日结报表是单日数据。要看月度汇总，请使用 **报表 > 销售报表**，选择月度时间范围。
  </FAQItem>
</FAQ>
