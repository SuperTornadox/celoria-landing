# 历史记录

查看和管理过去的日结记录，用于对账、审计和经营分析。

## 适用角色

- 经理 (Manager)
- 管理员 (Admin)

## 前置条件

- 已登录经理或管理员账号
- 拥有 `closeout:manage` 权限

## 查看历史

<Steps>

### 1. 进入日结页面

点击 **管理 > 日结**。

### 2. 切换到历史记录

点击 **历史记录** 标签。

### 3. 浏览记录列表

系统显示所有已完成的日结记录，每条显示：

| 列 | 说明 |
|----|------|
| 日期 | 日结对应的营业日期 |
| 总营收 | 当日净收入 |
| 小费总额 | 当日小费合计 |
| 现金 | 当日现金收款 |
| 刷卡 | 当日刷卡收款 |
| 状态 | 已完成 / 已锁定 |

</Steps>

<Screenshot src="/docs/screenshots/closeout-history-list.png" alt="日结历史记录" caption="日结页面底部的每日汇总历史记录" />

## 筛选和搜索

可以按以下条件筛选历史记录：

| 筛选条件 | 说明 |
|----------|------|
| 日期范围 | 选择开始和结束日期 |
| 门店 | 多门店时选择特定门店 |
| 状态 | 已完成、已锁定 |

## 查看日结详情

点击任意一条记录查看详情：

- **销售汇总** — 当日各类收入明细
- **支付核对** — 各支付方式的对账结果
- **小费分配** — 每位技师的小费分配详情
- **差异记录** — 如果有现金差异，显示金额和原因

详细报表内容见 [日结报表](/docs/manager/day-end-closeout/report)。

## 导出数据

历史日结数据可以导出用于：

| 用途 | 建议格式 | 操作 |
|------|---------|------|
| 月度对账 | Excel (.xlsx) | 选择日期范围 > 导出 Excel |
| 财务审计 | PDF | 逐日导出 PDF 存档 |
| 经营分析 | Excel (.xlsx) | 导出后在 Excel 中做数据透视 |
| 发送报告 | 邮件 | 点击发送，选择收件人 |

<Steps>

### 1. 选择日期范围

设置要导出的开始和结束日期。

### 2. 点击导出

点击 **导出** 按钮，选择格式。

### 3. 下载文件

文件自动下载到本地。

</Steps>

## 解锁已完成的日结

如果日结锁定后发现数据有误，管理员可以解锁：

<Steps>

### 1. 找到需要修改的日结记录

在历史记录中找到对应日期。

### 2. 点击解锁

点击 **解锁** 按钮（仅管理员可见）。

### 3. 填写解锁原因

说明为什么需要解锁修改，例如「发现遗漏的现金交易」。

### 4. 确认解锁

解锁后可以修改数据，修改完成后需要重新锁定。

</Steps>

<Callout type="warning">
解锁操作会记录在审计日志中，包括操作人、时间和原因。请谨慎使用。
</Callout>

## 常见问题

<FAQ>
  <FAQItem question="日结必须每天做吗？">
    强烈建议每天做。如果某天没有营业可以跳过。忘记日结时次日可以补做，但现金清点可能不准。
  </FAQItem>
  <FAQItem question="日结后发现有误怎么办？">
    联系管理员解锁日结记录，修改后重新锁定。所有修改都会记录在审计日志中。
  </FAQItem>
  <FAQItem question="多个经理可以同时日结吗？">
    不可以。日结是门店级操作，同一时间只能有一人进行。如果有人正在日结，其他人需要等待。
  </FAQItem>
  <FAQItem question="现金差异的合理范围是多少？">
    $5 以内通常是正常的找零误差。超过 $5 系统会提示黄色警告，超过 $20 为红色警告，需要说明原因。具体阈值可在设置中调整。
  </FAQItem>
  <FAQItem question="历史记录保存多久？">
    系统永久保存所有日结记录。建议每月导出一份 Excel 作为额外备份。
  </FAQItem>
</FAQ>
